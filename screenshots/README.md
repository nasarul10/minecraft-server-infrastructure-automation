# Suggested Screenshots

Adding a few screenshots will make the portfolio repository much stronger.

Recommended images to add here:

1. **Crafty dashboard** — crop out IP addresses, usernames, tokens, and player information.
2. **Discord slash commands** — show `/start`, `/status`, or `/backup` returning a successful response.
3. **Google Drive backup folder** — show dated backup archives; hide account details.
4. **Fabric startup log** — show Fabric/Minecraft version and successful `Done` startup while removing player/IP information.
5. **Performance profiling** — a sanitized Spark summary or `htop` screenshot showing the troubleshooting workflow.

Do not upload screenshots containing Discord tokens, RCON passwords, Crafty credentials, SSH details, player IPs, or Google OAuth information.
