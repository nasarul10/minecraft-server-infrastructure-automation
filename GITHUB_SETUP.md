## Push from your computer

Create an empty repository on GitHub first, then from this project directory run:

```bash
git remote add origin https://github.com/YOUR-USERNAME/minecraft-server-infrastructure-automation.git
git branch -M main
git push -u origin main
```

If you downloaded the clean ZIP rather than a folder containing `.git`, initialize it first:

```bash
git init
git add .
git commit -m "Initial portfolio project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/minecraft-server-infrastructure-automation.git
git push -u origin main
```
